# 🤖 AI-Based Resume Tracker

A full-stack web application that analyzes a resume against a job description and provides a resume match score, matching skills, missing skills, and improvement suggestions.

The project is designed to help students and job seekers understand how well their resume aligns with a particular job role.

---

## ✨ Features

- 📄 Resume input
- 💼 Job description input
- 📊 Resume-to-job match score
- ✅ Identification of matching skills
- ❌ Identification of missing skills
- 💡 Personalized improvement suggestions
- 💾 Stores analysis results in MySQL
- 🔗 Frontend and backend integration using REST API
- 📱 Responsive user interface
